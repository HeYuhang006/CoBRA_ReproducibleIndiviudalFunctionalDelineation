# Method definitions retained by this package

**Population model**: full within-hemisphere N×N FC; exact algebraic projection retains every FC entry. Width64, latent32; two residual surface convolutions; 128 mean-pooled *learned-feature* context tokens; two 4-head Transformer layers; vertex VAE. Group1000 steps; shared450-person cross-day50 epochs. The 128 tokens do not truncate the full-FC input.

**Personal model**: separately trained width128 neural group prior, same graph/token topology and latent32;1000 group steps. Reset all active weights from that prior for each independent personal fit. Thirty steps, lr2e-4; all ordered distinct-run reconstruction pairs, posterior-mean consistency, group/core/mesh/parameter regularizers. LR/RL observations are combined in the fit but remain independent runs in the reconstruction objective.

**Group parcellation**: encode training-group FC at completed population checkpoint. Concatenate μ32 and standardized LPE5 with weight1, K-means10 starts/300 iterations, independent resolutions. Connected seeded assignment, local polish, training-group raw functional objective, monotone connected boundary moves. No validation participant contributes to fitting this prior.

**Individual connected inference**: start from the corrected connected group labels. Fixed seeds/core and depth/size limits; candidate destinations must neighbor the moved boundary vertex; source parcel must remain connected after removal; move only when full objective improves. The personalized embedding/FC changes which boundary moves are favorable. Interior vertices do not spontaneously become new islands. Hard-connectivity ablation disables only the connectivity gate with the same fitted network and decoder inputs.

**18-network extension**: distributed networks can have anatomically distinct components. Fix a seed in each pre-existing component; forbid new components rather than enforcing one component per network. Report excess components relative to the network prior. SpatialWard9+9 is an areal control, not 18 semantic distributed networks.

**Distance normalization**: train-derived FC mean/SD conditional on geodesic bins; an explicit branch separate from raw FC. No per-validation-subject fitting of the normalization statistics. This operation reduces mean/variance dependence on distance; it does not prove statistical independence from distance.

**Symmetry / undirected FC**: raw standardized-time-series FC is C=YᵀY/T and is symmetric. Mesh Graph-CNN adjacency has both directions of each undirected cortical edge. FC is a vertex feature profile, not the mesh adjacency. The neural target uses training-reference column scale, X_ij=C_ij/s_j; different s_i and s_j can make X asymmetric. The linear decoder is unconstrained; the full N² reconstruction objective currently includes both orientations and the diagonal. After averaging, it is an explicitly defined full-profile loss; its two orientations need not carry equal effective raw-FC weighting under column scaling. No symmetry/PSD guarantee is claimed for decoder predictions. Application connectomes are computed separately from actual ROI time series, hence their raw correlation matrices are symmetric. Upper-triangle-only loss or a symmetric/Gram decoder would be a NEW architectural ablation, not an undocumented cleanup change.

**Data separation**: separate raw segments before zero-phase filtering; filter first, censor FD>.5mm, restandardize. Motion rotations in HCP regressors are degrees; radius50mm. Frozen ROI connectomes use independent REST2 measurements. Independently recalibrated ROI analyses are separate. Cross-day controlled fitting on both days followed by heldout tails is temporal-segment validation; independent long-term Retest provides another level of evidence.

**Baseline provenance**: DRFC500 group reference; CoBRA450 group and neural prior. Later HFR18 preserves publicly released author arithmetic and is checked against MATLAB; it is not bitwise original2015. Wang100 remains a Salehi-comparison-style adapted diagnostic with missing original weighting components. GPIP author distribution is private and byte-preserved; external eigs/T handling adapters are explicit. K18/K100 are non-native resolutions/extensions. Fixed20 GPIP iterations are a budget, not evidence of stable outer-loop labels.

**Reproducibility / specificity**: fixed group atlas ARI=1 by construction. Intra similarity must be considered alongside inter similarity and their gap; larger inter variance alone can reflect noise. Participant resampling avoids treating subject pairs or FC edges as independent people; tie-aware identification gives a fixed atlas chance rather than100% accuracy.

This package is a code organization and fresh-rerun entry point. It does not establish that CoBRA outperforms all baselines, that every live validation has finished, or that GPIP outer-loop convergence has been demonstrated. Such claims require the actual rerun outputs and fair paired comparisons.
